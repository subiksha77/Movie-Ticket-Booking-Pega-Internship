# Movie Ticket Booking Management Application

## Project Overview
A Pega-based Movie Ticket Booking Management Application developed as part of Pega's National Internship Program.

The application automates movie ticket booking workflows and helps manage movie shows, availability, booking requests, confirmation, and customer details.

## Technology
- Pega Platform
- Pega App Studio
- Pega Blueprint

## Key Features
- Submit Movie Ticket Request
- Check Show Availability
- Calculate Booking Cost
- Confirm Booking Request
- Maintain Movie and Show Data
- Review Booking Details
- Process Ticket Booking
- Notify Booking Confirmation
- Manage Booking SLA
